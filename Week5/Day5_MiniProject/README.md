# Mini Project: Student Performance Prediction

This regression project predicts final student scores and compares three models:

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

Run from the repository root:

```bash
.venv/bin/python Week5/Day5_MiniProject/student_performance_project.py
```

The script generates the dataset, handles missing values, trains each model,
evaluates MAE/MSE/R-squared, selects the lowest-MAE model, and saves predictions,
a comparison table, a chart, and project documentation.
